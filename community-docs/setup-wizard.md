# Setup wizard and setup packs

*[Leia em português](pt-BR/setup-wizard.md)*

Deck Shelves now has a **Setup wizard**: pick a starting point, see exactly what it adds, apply it. Nothing you already have is touched, and one tap undoes the last apply.

## Where it lives

- **Quick Access menu → Deck Shelves → the wand icon in the title bar** (next to the docs and settings icons) — always there, first run or not. On a fresh install the first-run banner offers it as a button too.
- At the **end of the first-run tour**, which now closes with three choices: *Configure now* (opens the wizard), *Start with the default* (the three default shelves, as before) or *Start from scratch* (nothing is created; the usual first-run prompts stay available later).

## The packs

- **Quick setup** — *Essential* (Favorites, Recently Played, Recently Added) and *Steam + non-Steam* (adds Installed and your non-Steam shortcuts).
- **Setup packs** — *Backlog rescue*, *Portable Deck*, *Rediscover* and *Living room*: each combines regular shelf templates with a few smart shelves, and *Living room* also turns on the first-shelf background art and the featured first game.
- **By device** — *Frame*, *Machine* and *Stream*: light starting points for a headset, a TV box and a play-anywhere setup.

Packs that fit your library (lots of never-played games, many installed games, long-untouched titles) are marked **Recommended for your library**, from the same statistics the Suggestions tab uses.

## What applying does, and does not do

- Adds the pack's shelves and smart shelves. A template you already have is listed as *already have* and skipped.
- Turns on only the settings the pack needs (for example smart shelves, or the first-shelf background art) and tells you which before you apply.
- Never removes or reorders anything you had. Every shelf it adds is a normal shelf: rename it, edit its filter, move it, delete it.
- **Undo the last setup** (in the wizard, shown while there is something to undo) removes only the shelves that apply added and puts back the settings it changed. Shelves you created afterwards stay.

## Tips

- Run two packs in a row if you like; the second one skips whatever the first already covered.
- Applying a pack never deletes shelves, so the safe way to try one is simply to apply it and undo if it isn't for you.
