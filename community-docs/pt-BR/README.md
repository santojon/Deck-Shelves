# Docs para comunidade — prontos para postar

*[Read in English](../README.md)*

Um arquivo por funcionalidade, escrito para Discussions do GitHub, anúncios
no Discord, e posts no Reddit — não são docs de planejamento interno. Cada
um explica o que a funcionalidade faz, por que você ia querer usar, como
exatamente ativar/desativar, e como resolver problemas, numa linguagem
simples que um usuário (não um contribuidor) consegue seguir.

Copie o conteúdo de um arquivo direto para uma Discussion / post no Discord
/ post no Reddit. Corte a seção "Solução de problemas" para um anúncio
curto se quiser; mantenha para um post fixado de Discussion que as pessoas
vão pesquisar depois.
