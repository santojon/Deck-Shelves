# Quick Search & Side Nav

*[Leia em português](pt-BR/quick-search-and-side-nav.md)*

Two fast-navigation tools for jumping around a big shelf setup without
scrolling forever.

## Quick Search

Press L1+R1 on any card to pop up a search box that fuzzy-matches against
every game across all your visible shelves — including cards that are
below the fold or still loading their info, so it genuinely searches
everything, not just what's currently rendered. Handles accented
characters sensibly (searching "Pokemon" finds "Pokémon").

After a short pause, the best match scrolls into view and gets focused
automatically. Close it with L1, R1, or B.

Two related settings:
- **Open virtual keyboard automatically** — on by default.
- **Search only on Enter** — off by default; turn it on if you'd rather
  type the whole query before it searches, instead of searching as you
  type.

## Side Nav

Press L1 twice on any card to slide in a panel listing every visible
shelf, in the order they appear on Home. It auto-focuses whichever shelf
you were just on, so you can jump straight to a different one without
scrolling past everything in between. Close it with R1+L1, B, or dpad-right.

## Rebinding these

Both have their own gamepad binding, changeable like any other — see
[Button bindings](button-bindings.md).

## Troubleshooting

- **Quick Search doesn't find a game I know is on a shelf.** Make sure that
  shelf is actually visible (not hidden) — Quick Search only searches
  what's currently shown on Home.
- **The overlay won't close.** L1, R1, or B should always close it
  regardless of whether a physical or virtual keyboard currently has
  focus — if none of those work, that's worth a bug report.
