# Works alongside your other plugins

Deck Shelves is built to coexist with the rest of the Decky ecosystem, not
replace it. A few specific plugins get direct integration:

## TabMaster

Deck Shelves reads your TabMaster tabs (both plain native tabs and
filter-based ones) so you can use them as a shelf source directly — no
need to rebuild a tab you already made in TabMaster as a Deck Shelves
filter from scratch. There's also a one-click **import** that converts a
TabMaster tab's filters into their closest Deck Shelves equivalent.

## UnifiDeck

If you use UnifiDeck to unify multiple storefronts into one library, Deck
Shelves detects which apps it manages and can filter/sort accordingly —
the two don't step on each other.

## Non-Steam Badges

If this plugin is installed, Deck Shelves' own "hide non-Steam badge"
option becomes available, since there's now a badge worth hiding.

## SteamGridDB, HLTB, CheatDeck

Confirmed to coexist cleanly — no conflicts, nothing special required from
you.

## CSS Loader themes

Covered in its own doc: [Theme compatibility](theme-compatibility.md).

## Does Deck Shelves replace any of these?

No — TabMaster organizes your library into tabs, UnifiDeck unifies
multiple stores into one library, CSS Loader themes restyle Steam's UI.
Deck Shelves adds a customizable, shelf-based Home screen on top of any (or
all) of them.
