# Getting started with Deck Shelves

*[Leia em português](pt-BR/getting-started.md)*

Deck Shelves adds your own custom rows ("shelves") to the Steam Deck Home
screen — built from your collections, library tabs, filters, or online
sources like your wishlist — configured entirely on the Deck itself,
gamepad-first, no desktop mode or config files.

## Installing

Two ways in: [ShelvesHub](shelveshub-install.md) (recommended, no Decky
Loader needed) or the [Decky Store](https://decky.xyz) if you're already
on Decky. Either way, once installed you'll find Deck Shelves' settings
from the Quick Access Menu (either its own tab, or inside Decky's plugin
list, depending which host you used).

## Creating your first shelf

1. Open Deck Shelves' settings and go to **Shelves**.
2. Add a shelf. You'll be asked to pick:
   - A **name**.
   - A **source** — where its games come from. Start with something
     simple like "Favorites" or "Installed" (a built-in template), or one
     of your own Steam collections or library tabs.
   - A **limit** (how many games it can show) and a **sort** (how they're
     ordered).
3. Save, back out to Home — your shelf is there.

There's a set of ready-made templates (Favorites, Recently Played,
Installed, Most Played, and more, including online ones like "On Sale") if
you'd rather start from a preset than build a source from scratch — pick
one when adding a shelf and tweak from there.

## The two places you'll configure things

- **The full settings page** — the complete editor, best for building or
  editing shelves and filters.
- **The sidecar** — a compact panel that opens straight over the Quick
  Access Menu for quick toggles without leaving the game/Home you're on.

Both read and write the same settings — use whichever's more convenient in
the moment.

## Undoing a mistake

Every shelf and every setting can be edited or deleted from the same
screen you created it in. If you want a clean slate, **Profiles** let you
save/restore whole configurations (see
[Profiles & Auto-Switching](profiles-and-triggers.md)) — including a
built-in "Default" profile that's a genuine factory reset.
